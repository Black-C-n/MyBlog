# 04 学习路线

## 第一轮：会运行（1 天）

1. 用 IDEA 导入 Maven。
2. 启动 MySQL 和应用。
3. 注册账号，新增文章、标签、相册和留言。
4. 知道 `application.properties` 在哪里。

## 第二轮：看懂请求（2～3 天）

1. 给登录 Controller 打断点。
2. 跟进 UserService 和 Repository。
3. 查看 Session 中的登录用户。
4. 给文章详情打断点，观察阅读量变化。

目标：不看文档也能画出 Controller → Service → Repository → MySQL。

## 第三轮：看懂 JPA（3～5 天）

1. 对照 SQL 表阅读 6 个 Entity。
2. 学会 `@Entity`、`@Table`、`@Id`、`@Column`。
3. 学会 `@ManyToOne`、`@ManyToMany` 和 `@JoinTable`。
4. 打开 Hibernate SQL 日志，观察 Repository 生成的 SQL。
5. 理解分页页码为什么要从网页的 1 减成 JPA 的 0。

## 第四轮：自己改功能（约 1 周）

按难度依次练习：

1. 给文章列表增加标题搜索；
2. 增加“按标签筛选”；
3. 增加文章点赞按钮；
4. 后台增加分页；
5. 给表单增加更详细错误提示；
6. 给 Controller 写 MockMvc 测试。

每次改动坚持：先写需求 → 找 Controller → 找 Service → 找 Repository → 写测试。

## 第五轮：准备面试

做到下面四件事：

1. 3 分钟讲清项目背景、技术选择和难点；
2. 现场打开密码兼容、阅读量和后台隔离代码；
3. 能解释一次登录和一次文章查询；
4. 主动说出项目不足及改进方案。

不要背整段答案。用自己的语言讲“遇到了什么问题、为什么这样设计、怎样验证”。
